# 依赖故障注入（假降级的四种形态）
## 四种假降级（全部读不出来，只能打断一次看）

| 形态 | 表现 |
|---|---|
| 不可达 | catch 写了，但更早的地方就抛了 / 错误类型不匹配 / 上层超时先到 |
| 语义错 | fallback 值被下游误读（「查不到」被读成「没有」） |
| 无界 | SDK 隐式重试 × 外层重试 = 实际等待远超预算 |
| 静默 | 降级动作是控制面写（刷锚点、置变量），不是业务补偿 |

## 怎么用

`installFaults([{ host, mode: 'http5xx' }])` 替换 `globalThis.fetch`，不改业务代码。
默认 `strict`：**未声明的出站一律抛错** —— 把「零真实出站」变成机制，而不是「我记得都 mock 了」。

## 纪律

- 每条规则至少命中一次（`expectHits`），否则测的是空气；
- 探针必须先对旧实现判红，红了才算有效。
